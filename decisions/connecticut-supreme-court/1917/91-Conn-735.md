# Blondin v. Connecticut Co.

## Majority (Per Curiam.)

Per Curiam.
The above-entitled actions were tried together upon the same evidence, and a verdict in each case was directed for the defendant. We think the record shows that there was evidence upon which the cases should have been submitted to the jury.
There is error and a new trial is ordered in each case.
